# 도로/건물 단위 날씨 시각화 설계

## 개요

줌 레벨 15 이상에서 개별 도로와 건물에 날씨 효과를 적용하는 상세 시각화 시스템

## 줌 레벨별 시각화 단계

### 1단계: 전체 보기 (zoom < 11)
- **3D 원기둥**: 각 구의 날씨를 높이와 색상으로 표현
- **용도**: 서울시 전체 날씨 개요 파악

### 2단계: 구 단위 (zoom 11-14)
- **구름/비 파티클**: 3D 파티클 시스템으로 현실적 날씨 표현
- **용도**: 구별 상세 날씨 현상 관찰

### 3단계: 동 단위 (zoom 15+) - **신규 구현**
- **도로/건물 시각화**: 개별 도로와 건물에 날씨 효과 적용
- **용도**: 미시적 날씨 영향 분석

## 기술 스택

### Mapbox Vector Tiles (MVT)
- **데이터 소스**: `mapbox://mapbox.mapbox-streets-v8`
- **레이어**: `building`, `road`, `water`
- **장점**: 실시간 로딩, 높은 성능, 정확한 지리 데이터

### deck.gl MVTLayer
- **역할**: Mapbox 벡터 타일을 deck.gl에서 렌더링
- **기능**: 동적 색상, 높이, 투명도 제어
- **성능**: GPU 가속 렌더링

## 시각화 효과 설계

### 건물 시각화
```typescript
// 강수량에 따른 건물 효과
- 맑음: 기본 건물 색상
- 약한 비: 건물 표면 어두워짐 (젖은 효과)
- 비: 건물 색상 진해짐 + 반사 효과
- 폭우: 진한 색상 + 물 고임 표현 (바닥층 하이라이트)
```

### 도로 시각화
```typescript
// 강수량에 따른 도로 효과  
- 맑음: 일반 회색 도로
- 약한 비: 어두운 회색 (젖은 아스팔트)
- 비: 진한 회색 + 미끄러짐 표시
- 폭우: 매우 진한 색상 + 물 웅덩이 효과
```

### 수역 시각화
```typescript
// 강수량에 따른 물 표면 효과
- 맑음: 고요한 수면 (연한 파랑)
- 비: 물결 효과 (중간 파랑)
- 폭우: 격렬한 물결 + 높은 채도
```

## 색상 팔레트

### 건물 색상 시스템
```typescript
const buildingColors = {
  clear: [200, 200, 200, 180],      // 연한 회색 (기본)
  lightRain: [160, 160, 160, 200],  // 어두운 회색 (젖음)
  rain: [120, 120, 130, 220],       // 진한 회색 (반사)
  heavyRain: [80, 90, 120, 240]     // 매우 진한 색 (물 고임)
};
```

### 도로 색상 시스템
```typescript
const roadColors = {
  clear: [150, 150, 150, 180],      // 일반 아스팔트
  lightRain: [100, 100, 100, 200],  // 젖은 아스팔트
  rain: [70, 70, 80, 220],          // 진한 젖은 도로
  heavyRain: [40, 50, 70, 240]     // 물 웅덩이
};
```

## 성능 최적화

### 레벨별 LOD (Level of Detail)
- **줌 15-16**: 주요 도로 + 큰 건물만
- **줌 17+**: 모든 도로 + 모든 건물

### 동적 로딩
- 뷰포트 기반 타일 로딩
- 거리별 렌더링 품질 조정
- 메모리 효율적 캐싱

### GPU 최적화
- 인스턴스 렌더링
- 배치 처리
- 셰이더 최적화

## 구현 단계

### Phase 1: 기본 구조
1. MVTLayer 추가
2. 줌 레벨 감지
3. 기본 건물/도로 렌더링

### Phase 2: 날씨 효과
1. 날씨 데이터 매핑
2. 색상 시스템 적용
3. 동적 업데이트

### Phase 3: 고급 효과
1. 애니메이션 효과
2. 실시간 업데이트
3. 상호작용 추가

## 예상 파일 구조

```
│   └── roadEffects.ts            # 도로 효과 로직

```

## 기대 효과

### 사용자 경험
- 현실적이고 몰입감 있는 날씨 시각화
- 도시 계획적 관점에서의 날씨 영향 분석
- 미시적 수준의 정밀한 정보 제공

### 기술적 효과
- deck.gl + Mapbox 생태계 활용
- 확장 가능한 아키텍처
- 성능 최적화된 렌더링
